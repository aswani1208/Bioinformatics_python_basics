## Notes

### Week 1 — Python Basics via DNA Sequences
Learned core Python (variables, string methods, f-strings, basic math) by working with DNA sequences instead of generic examples. Key concepts:
- Strings and string methods (`.count()`, `in`)
- f-strings for formatted output
- GC content calculation — a real metric used in genomics
- Reverse complement logic (A↔T, C↔G)
- Motif detection using the in operator (e.g. checking if "CGAT" appears in a sequence)
